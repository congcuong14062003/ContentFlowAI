# Phase 07 — Content editor progress

This phase is in progress, not signed off. The current editor consumes Phase 06 generated DRAFT/revision1 records. `ContentRevision` has additive nullable title/actor fields for historical compatibility; new revisions record both and remain immutable. `PUT /api/v1/workspaces/:workspaceId/content/:id` requires `expectedVersion`, title, text and optional validated TipTap JSON. The same transaction conditionally increments version, writes the revision and audits the actor. A stale version returns 409; `POST :id/restore` creates a new revision from an old snapshot. GET list, item and revision metadata are tenant scoped; edit/restore require editor+ and only DRAFT status.

The protected library and editor routes use Phase 02 components and vi/en strings. TipTap StarterKit provides formatting/undo/redo. Autosave debounces 900 ms; route and unload guards protect pending changes. Refetch does not overwrite dirty, saving, error or conflict state. On conflict the local document remains visible and the user can copy it before choosing to reload. The editor shows outline metadata, version/history, preview, copy and text/Markdown export. Only a saved generated draft is editable at present; a separate standalone create/duplicate/template flow has not been implemented.

AI actions currently reuse the real Phase 06 `rewrite` tool and Phase 05 gateway/credit engine. The user selects text, requests clarity/shorten/expand/change tone, sees server maximum credit hold and confirms the paid call. The request uses the draft brand/platform/language and only the selected source text. The result is inserted only if the editor JSON, selection text and version still match the captured state. No automatic retry of unknown outcomes or second charge is made; same in-memory operation key is used if the submission response is lost while the editor stays mounted. The AI result persists in generation history. Actual paid vendor routing remains disabled without operator configuration; fixture integration exercises billing. Other AI suggestions (hashtags/CTA) are pending.
